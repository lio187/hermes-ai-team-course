## Reconciliation

`references/SPEC.md` is the reconciled authority. Statements labelled **CONFIRMED** are supported across the tutorial evidence. Statements labelled **CURRENT HERMES** are adaptations grounded in the current Hermes Desktop Plugin SDK, installed source/docs, and live CLI evidence captured during specification work. Tutorial-only infrastructure and unsafe remote-access practices were rejected rather than copied.

## Product lineage

The tutorial's useful information architecture—overview, profiles, tasks, schedule, and library—was retained. Its standalone VPS dashboard, fixed agent roster, custom activity database, public networking footprint, broad mutation UI, and insecure SSH assumptions were not retained. The resulting artifact is a native, read-only, dynamically discovered Hermes Desktop surface.
